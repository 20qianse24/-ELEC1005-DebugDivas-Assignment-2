Assignment 2 ELEC1005

# Project Overview:
Unified Communications and team management platform for the NSW State Emergency Service to organise spntaneous volunteer allocation to unexpected emergencies.

# Targeted Problem:
Current primary communication channels with volunteer rescuers are scattered across social media platforms, resulting in unreliable response times and coordination of volunteers and resources. A unified platform keeps all communications and information on emergencies and hazards in one central location and easily accessible.

# Users:
Made for Volunteers and Duty Officers involved in responding to unexpected emergencies

# Key features:
- Duty Officers:
  - Register new emergencies
  - View worked hours of volunteers to prevent overexertion
  - Mark emergencies as complete
- Volunteers AND Duty Officers:
  - Report hazards at emergency sites
  - Communicate directly with team members via a groupchat
  - Recieve and accept/decline assigments
  - View relevant information on emergencies and hazards

## Quick start
1. Clone repository
2. Run the app
3. Sign up as a volunteer or duty officer and login
4. Once redirected to dashboard page, click on an emergency assignment to view and accept/decline
5. Duty officers can click on "Report an Emergency" to send an assignment call-out to volunteers

# Common confusion
- Volunteers logging on for the first time will not have any upcoming assignments until a new one is created by a duty officer
- If no assignments are visible, this means there are no current active emergencies
- Only duty officers can create emergencies
- Declined assignments disappear from the user's dashboard and are not accessible again
- ### WARNING: Running the test suites will reset ALL user assignments to PENDING
